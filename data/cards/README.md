# Real card images

Data from real sonorine cards, for testing the pipeline beyond the simulated
cards. Add new cards here with a line below on where each came from.

- `ezra_card.jpg` — 2000² JPEG from Ezra's earlier groove-tracking work
  (given by Adam, Nov 2026): a grey rendering of the card's surface (flat =
  mid-grey, grooves dark), with Ezra's traced path drawn faintly in blue
  (mostly lost in the JPEG's chroma). Spacing 9.9 px, ~52 turns, groove
  annulus r ≈ 390–960 px about (1014, 1001). Not calibrated depth. Results:
  `experiments/ezra_card/README.md`.

Tomaz's results on sonorine_001 (figures only, no depth maps yet) are in
`../../tomaz-results/` (outside this repo).
